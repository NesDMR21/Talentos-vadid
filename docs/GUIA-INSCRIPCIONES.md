# Guía — Inscripciones del sitio web

## ¿Qué es esto?

Cuando alguien llena el formulario de inscripción en la página web (sección "Empieza tu historia"), la solicitud llega por **dos caminos al mismo tiempo**:

1. **WhatsApp** — se abre un chat con el mensaje ya escrito, como hasta ahora.
2. **Hoja de Google** — la inscripción queda guardada como una fila nueva, y llega un **correo de aviso** a `clubvadid.futbol@gmail.com`.

Así, si el WhatsApp no se llega a enviar (por ejemplo, la persona cierra la pestaña sin dar "Enviar"), la inscripción no se pierde: queda guardada en la Hoja.

## Dónde ver todas las inscripciones

**Link a la Hoja de Google:** _(pendiente — se agrega aquí una vez creada, ver nota abajo)_

Ábrelo cuando quieras y vas a ver una tabla con una fila por cada inscripción, con estas columnas:

| Columna | Qué significa |
|---|---|
| Fecha | Día y hora en que se envió el formulario |
| Nombre del jugador | Nombre completo del niño/joven a inscribir |
| Edad | Edad del jugador |
| Categoría | Categoría de interés (año/Sub-20, Sub-16, Sub-12, Baby Fútbol) |
| Acudiente | Nombre del acudiente (si lo escribieron — es opcional) |
| Email | Correo de contacto |
| Teléfono | Teléfono/WhatsApp de contacto |
| Mensaje | Comentario adicional (si lo escribieron — es opcional) |

Puedes ordenar por fecha, buscar un nombre, o marcar con color las que ya contactaste — es una hoja de cálculo normal, como Excel.

## Cuando llega el correo de aviso

Cada vez que alguien se inscribe, llega un correo a `clubvadid.futbol@gmail.com` con el resumen de esa inscripción. Sirve para enterarte al momento, sin tener que estar revisando la Hoja todo el tiempo. La Hoja sigue siendo el lugar donde queda **todo el historial junto**.

## Si algo no funciona

Si un día no llega el correo de aviso, o una inscripción no aparece en la Hoja, no pasa nada grave — revisa igual el WhatsApp del club, que sigue funcionando siempre. Y avísale a Diego (Juan) para revisar la conexión con la Hoja.
